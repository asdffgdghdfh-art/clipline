# ClipLine 开发记录

## 设计取舍

用户痛点是重复在「源页面截图/复制」与「目标聊天窗口粘贴」之间切换。V0.1 先实现 **收集 → 暂存 → 批量拖图/复制文字** 的完整闭环，不添加账号、云同步、OCR、模型或后台服务器。

截图来源分两路：

1. 剪贴板：轮询 `NSPasteboard.general.changeCount`，新图片拷贝到本地目录，文字仅在显式开启后记录。
2. 文件夹：默认扫描 Desktop，匹配截图命名的常见中文/英文前缀。启动时先登记已有文件，因此不会把桌面历史截图倒灌进暂存。

输出分两路：

- 批量图片：`NSDraggingItem` + `beginDraggingSession`，每张独立文件 URL；拖入兼容多附件的 Web/桌面软件。
- 文字：合并到系统剪贴板，用户自行在目标输入框粘贴。

**不**暗示任意第三方应用支持混合图片+文字的单次粘贴。文件 URL 的剪贴板写入是辅助模式，不能保证浏览器可以粘贴。

## 本地目录

`~/Library/Application Support/ClipLine/records.json`

`~/Library/Application Support/ClipLine/images/<uuid>.png`

JSON 索引只保存本地文件名（不包含随来源复制的可识别路径），最多 80 条记录，删除时清理 PNG 副本。

## 验收清单（必须在 Mac 上人工验证）

- [ ] 首次打开显示晾衣绳，菜单栏出现 ClipLine。
- [ ] 选择截图保存到桌面，连续按 ⇧⌘4 截取三次，出现三张卡片。
- [ ] 使用 Control + Shift + Command + 4 剪到剪贴板，新增一张卡片。
- [ ] 自动文字收集默认关闭，复制一段文本不会出现；主动打开后能新增便签。
- [ ] 选中两张图片，拖动蓝色区域到接受多文件的网页上传框，得到两份附件。
- [ ] 多段文本勾选后「复制文字」，目标应用收到拼接结果。
- [ ] 关闭再打开，卡片仍存在；取下、清空会删副本、不删桌面原文件。
- [ ] 切换截图监听路径只收新截图；暂停收集后不新增。
- [ ] 系统设置中的桌面文件访问授权拒绝/允许都能合理处理。
